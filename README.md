## 1. Project overview

This project trains a Ridge regression baseline on the scikit-learn Diabetes dataset, logs parameters/metrics/model/artifacts to MLflow, and checks for data drift and prediction drift between reference and simulated current data.

- 442 records and 10 numeric input features.
- 60:40 reference/current split with a fixed random seed.
- Simulated changes: `bmi + 0.06`, `bp + 0.05`, `s5 × 1.5`, plus negligible noise to `age`.
- Feature drift: two-sample Kolmogorov–Smirnov (KS) test and Population Stability Index (PSI).
- Drift rule: KS p-value `< 0.05` **or** PSI `> 0.2`.
- Outputs: CSV report, summary JSON, and distribution/PSI plots.

## 6. Drift methodology

### KS test

The two-sample KS test compares the empirical distributions of reference and current values. A p-value below 0.05 is treated as evidence that the distributions differ.

### PSI

PSI compares the proportion of values in reference quantile bins with the proportions in current data. The report flags PSI above 0.2 as notable drift. PSI is a heuristic, so interpret it alongside the KS test and domain context.

### Metrics and interpretation

The script logs reference/current RMSE, MAE, and R², as well as `drifted_features`, `drift_share`, `prediction_ks_stat`, and `prediction_ks_pvalue`. Since only the input features are modified, target labels remain the held-out labels from the original dataset. Similar metrics in this synthetic experiment do not prove a deployed healthcare model is safe; real performance should be checked when recent ground-truth labels become available.
